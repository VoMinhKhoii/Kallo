**Screen 3: `components/onboarding/screen-cooking.tsx`** — `'use client'`

Props: `{ defaultValues: Partial<CookingHabits>; regionalProfile: RegionalProfile | null; onChange: (data: CookingHabits) => void }`

**One-time pre-population with useRef guard:**
```ts
const hasPrePopulated = useRef(false);

useEffect(() => {
  if (!hasPrePopulated.current && allCookingFieldsNull(defaultValues) && regionalProfile) {
    const defaults = REGIONAL_COOKING_DEFAULTS[regionalProfile];
    // Set all form fields from defaults
    Object.entries(defaults).forEach(([key, val]) => setValue(key as any, val));
    hasPrePopulated.current = true;
  }
}, []); // Empty deps — runs once on mount only
```
- `allCookingFieldsNull`: checks if oilUsage, fatTrim, boneAwareness, defaultRicePortion, sugarBraised are ALL null/undefined in defaultValues
- If defaultValues already has values (resuming from saved step 3), skip pre-population
- If regionalProfile is null (edge case — shouldn't happen in normal flow), use neutral defaults: `{ oilUsage: 'normal', fatTrim: 'eat_all', boneAwareness: false, defaultRicePortion: 'medium', sugarBraised: 'medium' }`

**Form fields** (react-hook-form with `zodResolver(cookingHabitsSchema)`):

1. **Oil Usage**: 3-option segmented control (Ít dầu / Bình thường / Nhiều dầu)
   - Values: 'minimal' / 'normal' / 'heavy'

2. **Fat Trimming**: 3-option segmented control
   - Label: "Khi ăn thịt, bạn xử lý mỡ thế nào?"
   - Options: "Bỏ mỡ" (Trim) / "Ăn nguyên" (Eat as-is) / "Tùy món" (By dish)
   - Values: 'trim' / 'eat_all' / 'by_dish'
   - SINGLE toggle — server action fans out to fatTrimPork/Chicken/Fish

3. **Bone Awareness**: Switch/checkbox
   - Label: "Bạn có cân nhắc xương khi ước lượng phần ăn?"

4. **Default Rice Portion**: 3-option segmented control
   - Label: "Khẩu phần cơm mặc định"
   - Options: "Nhỏ ~150g" / "Vừa ~200g" / "Lớn ~300g"
   - Values: 'small' / 'medium' / 'large'

5. **Sugar in Braised Dishes**: 3-option segmented control
   - Label: "Mức đường trong món kho?"
   - Options: "Ít" (Low) / "Vừa" (Medium) / "Nhiều" (High)
   - Values: 'low' / 'medium' / 'high'

All fields are discrete selectors — report onChange immediately on every change.
