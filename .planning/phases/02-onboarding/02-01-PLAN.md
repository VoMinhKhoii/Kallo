**lib/onboarding/tdee.ts** — Pure calculation functions:

`calcBMR(metrics: BodyMetrics): number`
- Mifflin-St Jeor formula:
  - Male:   (10 × kg) + (6.25 × cm) - (5 × age) + 5
  - Female: (10 × kg) + (6.25 × cm) - (5 × age) - 161
- Returns raw BMR as a number (no rounding — rounding happens in TDEE)

`calcTDEE(bmr: number, activityLevel: ActivityLevel): number`
- Returns `Math.round(bmr * ACTIVITY_MULTIPLIERS[activityLevel])`

`calcMacroGrams(calories: number, carbSplit: CarbSplit): MacroTargets`
- Given total calories and a CarbSplit key:
  - proteinG = Math.round((calories * ratio.protein / 100) / 4)
  - fatG = Math.round((calories * ratio.fat / 100) / 9)
  - carbsG = Math.round((calories * ratio.carbs / 100) / 4)
- Returns `{ calories: Math.round(calories), proteinG, carbsG, fatG }`

`calcDailyTargets(tdee: number, goal: Goal, aggression: Aggression | null, carbSplit: CarbSplit, deficitOverride?: number | null): MacroTargets`
- **CRITICAL TYPE: deficitOverride is `number | null | undefined`** — accepts null from OnboardingProfile.deficitOverride and undefined when omitted. The `??` operator handles both.
- For 'maintaining': calories = tdee (deficitOverride and aggression ignored)
- For 'cutting':
  - adjustment = deficitOverride ?? AGGRESSION_PRESETS[aggression!]
  - calories = tdee - adjustment
- For 'bulking':
  - adjustment = deficitOverride ?? AGGRESSION_PRESETS[aggression!]
  - calories = tdee + adjustment
- Then returns `calcMacroGrams(calories, carbSplit)`
- **Add this comment above the return:** `// NOTE: calories may go negative if deficitOverride > tdee. Caller (Server Action) must clamp: Math.max(result.calories, 500) before persisting.`

Import types from `./types` and constants from `./constants`. Export all 4 functions.

**CRITICAL TYPE ALIGNMENT RULE:** Every schema field must produce a z.infer type matching the corresponding OnboardingProfile interface field. Use `.nullable()` for `T | null`, NEVER `.optional()` for nullable fields (produces `T | undefined`).

- `bodyMetricsSchema`: biologicalSex z.enum(['male','female']), weightKg z.number().min(30).max(300), heightCm z.number().int().min(100).max(250), age z.number().int().min(13).max(100), activityLevel z.enum(['sedentary','light','moderate','very_active']). All fields required.

  - deficitOverride: `.nullable()` only → inferred type `number | null`
